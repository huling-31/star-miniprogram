# 星辰 - AI情绪陪伴微信小程序
> 面向情绪困扰用户的心理陪伴小程序，支持普通用户 / 关联方双身份登录

## 📖项目简介
本项目为微信原生小程序，实现AI语音倾诉、文字暖心交流、情绪数据统计、历史情绪报告；关联方登录可查看用户情绪分析报告、书写暖心留言，辅助关怀抑郁群体。

## ✨功能清单
- 注册、登录，身份选择：普通用户 / 关联方
- 语音对话：按住说话，声波动画，确认结束通话，对话销毁
- 静音文字交流页面
- 今日情绪数据、历史情绪报告列表，点击跳转详情
- 关联方专属页面：情绪分析报告、暖心留言（多条留言带时间戳）

## 🛠️技术栈
微信原生小程序 WXML / WXSS / JavaScript
本地模拟数据（前端模拟存储，适合作品集展示）

## 🚀如何运行
1. 下载本仓库源码
2. 打开微信开发者工具，导入项目文件夹
3. AppID 选择【测试号】即可直接编译预览
4. 勾选：不校验合法域名，模拟器/手机扫码预览

## 💡项目亮点
1. 双角色权限隔离：普通用户、关联方两套主页
2. 交互细节：声波动画、确认弹窗、自动滚动聊天窗口
3. 心理报告模块，支持关联方留言，记录留言历史版本
